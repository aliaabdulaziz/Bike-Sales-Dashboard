# Bike Sales — Excel Dashboard

An Excel portfolio project using data preparation, pivot tables, and an interactive dashboard to explore bike-sales patterns.

## Deliverable
[Download the Excel workbook](Bike%20Sales%20Dashboard.xlsx).

## Approach
The portfolio describes filtering and recoding marital-status and gender fields, creating age brackets, and building pivot tables and a dashboard.

## How to view
Download the workbook and open it in Microsoft Excel. Explore its worksheets and available dashboard controls. Excel Online may render some workbook features differently.

## Documentation status
The workbook is the primary deliverable. A dashboard screenshot, dataset-source citation, and quantified findings have not yet been added. The workbook was not executed or independently audited when this README was written; no commercial sales impact is claimed.
